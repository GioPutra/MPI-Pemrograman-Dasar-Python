# MPI Pemrograman Dasar Python

## Deskripsi
MPI (Multimedia Pembelajaran Interaktif) Pemrograman Dasar Python adalah aplikasi desktop yang dirancang untuk membantu siswa mempelajari dasar-dasar pemrograman Python melalui materi pembelajaran dan kuis interaktif.

## Tujuan
Membantu siswa memahami konsep dasar pemrograman Python secara mandiri, interaktif, dan mudah dipahami.

## Fitur Aplikasi
1. Menu utama aplikasi.
2. Empat materi pembelajaran Python:
   - Pengenalan Python
   - Variabel
   - Tipe Data
   - Operator Dasar
3. Kuis dengan tiga tingkat kesulitan: Mudah, Menengah, dan Sulit.
4. Soal kuis yang dipilih secara acak.
5. Pembahasan jawaban yang menampilkan status benar atau salah, jawaban yang tepat, dan penjelasan.
6. Tampilan hasil kuis dan nilai akhir.
7. Penyimpanan nilai kuis secara otomatis.
8. Riwayat nilai yang mencatat tanggal, tingkat kesulitan, jumlah jawaban benar, dan nilai akhir.

## Teknologi
- Bahasa pemrograman: Python
- Antarmuka: Tkinter
- Penyimpanan data: JSON
- Modul pendukung: Random, Datetime, dan OS
- Platform: Desktop Windows

## Cara Menjalankan Aplikasi
1. Pastikan Python sudah terinstal.
2. Buka folder proyek melalui VS Code.
3. Buka terminal pada folder proyek.
4. Jalankan perintah:

   `python main.py`
