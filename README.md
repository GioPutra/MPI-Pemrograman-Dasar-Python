# MPI Pemrograman Dasar Python

## Deskripsi
MPI (Multimedia Pembelajaran Interaktif) Pemrograman Dasar Python merupakan aplikasi desktop yang dirancang untuk membantu siswa mempelajari dasar-dasar pemrograman Python melalui materi pembelajaran dan kuis interaktif.

## Tujuan
Membantu siswa memahami konsep dasar pemrograman Python secara mandiri, interaktif, dan mudah dipahami.

## Fitur Aplikasi
1. Dashboard atau menu utama aplikasi.
2. Empat materi pembelajaran Python:
   - Pengenalan Python
   - Variabel
   - Tipe Data
   - Operator Dasar
3. Fitur pencarian materi pembelajaran.
4. Kuis dengan tiga tingkat kesulitan: Mudah, Menengah, dan Sulit.
5. Pemilihan soal kuis secara acak.
6. Pembahasan jawaban yang dilengkapi penjelasan.
7. Tampilan hasil kuis dan nilai akhir.
8. Penyimpanan nilai kuis secara otomatis.
9. Riwayat nilai kuis.
10. Statistik nilai.
11. Grafik perkembangan nilai.
12. Ringkasan progres belajar.
13. Profil pengguna untuk menyimpan identitas pengguna.
14. Ekspor riwayat nilai ke format CSV.
15. Fitur navigasi materi dan penyalinan contoh kode.

## Teknologi yang Digunakan
- Bahasa pemrograman: Python
- Antarmuka aplikasi: Tkinter
- Penyimpanan data: JSON
- Format ekspor data: CSV
- Modul pendukung: Random, Datetime, dan OS
- Platform: Desktop Windows

## Cara Menjalankan Aplikasi
1. Pastikan Python sudah terinstal di komputer.
2. Buka folder proyek melalui Visual Studio Code.
3. Buka terminal pada folder proyek.
4. Jalankan perintah berikut:

   `python main.py`
