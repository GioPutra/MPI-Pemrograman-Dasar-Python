# MPI Pemrograman Dasar Python

## Deskripsi
MPI (Multimedia Pembelajaran Interaktif) Pemrograman Dasar Python adalah aplikasi desktop yang dirancang untuk membantu siswa mempelajari dasar-dasar pemrograman Python melalui materi pembelajaran dan kuis interaktif.

## Tujuan
Membantu siswa memahami konsep dasar pemrograman Python secara mandiri dan interaktif.

## Teknologi
- Bahasa pemrograman: Python
- Antarmuka: Tkinter
- Platform: Desktop Windows

## Status Proyek
Tahap 1: Pembuatan tampilan awal aplikasi.

## Pengembang
Proyek pembelajaran siswa SMK.
